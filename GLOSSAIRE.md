# Glossaire FR — Underrail

## Règle d’or (demandée)
| | Langue |
|---|---|
| **Nom de base** (skill, attribut, feat, ability, status, check `::[Guns]::`) | **EN** |
| **Description** (texte d’aide sous le skill, tooltip, effet…) | **FR** |

Exemple : label **Stealth** + texte *« Moins de chances de se faire spot en furtif… »*

| Type | Affichage |
|---|---|
| Skills | Guns, Stealth, Hacking, Melee, Dodge, Evasion… **EN** |
| Base abilities | Strength, Dexterity, Agility, Constitution, Perception, Will, Intelligence **EN** |
| Psi schools | Thought Control, Psychokinesis, Metathermics, Temporal Manipulation **EN** |
| Feat / ability names | **EN** (clé = nom) |
| Checks en dialogue | `::[Persuasion]::` `::[Mercantile]::` `::[Electronics]::` **EN** |
| Descriptions | **FR** gaming |
